Setiap paket dari PDF sumber dipisahkan menjadi dua kelompok: 4 paket **Umum (Pedagogi Umum, 30 soal/paket)** dari nomor 51–80 yang dinomori ulang 1–30, dan 4 paket **Program Studi PGSD (PCK, 50 soal/paket)** dari nomor 1–50. Program studi **Teknik Mesin** disediakan di `TRYOUT_PROGRAMS` untuk penambahan paket PCK berikutnya. Teks, pilihan atau pernyataan, kunci, dan pembahasan dicocokkan dengan dua hasil ekstraksi PDF. Penomoran, urutan pilihan, dan label kategori dipertahankan. Spasi dan tanda hubung akibat pergantian baris disesuaikan untuk tampilan web. Tinjauan render 156 halaman menunjukkan stimulus berbentuk teks, termasuk notasi matematika pada beberapa soal. Tidak ditemukan gambar, diagram, grafik, atau tabel stimulus.

Sampul PGK Kategori, PGK MCMA, dan Simulasi memuat petunjuk umum yang sama dengan PG Biasa. Jenis respons web mengikuti petunjuk pengerjaan dan struktur masing-masing soal. PGK MCMA PCK menggunakan minimal dua pilihan sesuai halaman 2, sedangkan Pedagogi Umum menggunakan dua sampai empat pilihan sesuai halaman 25. Untuk Simulasi, jenis respons mengikuti label format pada setiap nomor.

[CSV konversi](konversi.csv) memetakan setiap nomor ke halaman PDF untuk soal, kunci, dan pembahasan. Durasi latihan dikonfigurasi 50 menit untuk paket 30 soal dan 90 menit untuk paket 50 soal.
